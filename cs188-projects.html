Five projects from CS 188 at UC Berkeley, each an AI technique built into a working agent and measured.

Project 1 Summer 2026
DFS
AI | Search

Search: Pathfinding in Pacman

General-purpose graph search for Pacman: DFS, BFS, uniform-cost and A*, then harder problems (visit all four corners, eat every dot) that need a custom state representation and admissible heuristics. My A* heuristics find the same optimal paths while expanding up to 75% fewer nodes.

Project 2 Summer 2026
Minimax
AI | Game Playing

Multi-Agent Search: Pacman vs. Ghosts

Adversarial search for Pacman against one or more ghosts: a reflex agent, depth-limited minimax, alpha-beta pruning and expectimax, plus a hand-designed evaluation function. Alpha-beta picks the same move as minimax while generating 88% fewer game states.

Project 3 Summer 2026
MDPs
AI | Reinforcement Learning

Reinforcement Learning: MDPs and Q-Learning

Solving Markov decision processes with value iteration when the model is known, then learning without a model through Q-learning. Approximate Q-learning with a few features wins every test game on a full-size board after only 50 training games.

Project 4 Summer 2026
Bayes nets
AI | Probabilistic Inference

Ghostbusters: Probabilistic Tracking

Pacman hunts ghosts he cannot see, using only noisy distance readings. I implemented Bayes net inference with variable elimination, exact HMM tracking with the forward algorithm, and a particle filter; a greedy hunter using these beliefs wins every test game.

Machine Learning

Machine Learning: Neural Nets from Scratch

A perceptron, a regression network, an MNIST digit classifier and a recurrent language identifier, all built on a minimal autodiff library rather than PyTorch. The digit classifier reaches 97.5% test accuracy and the RNN names a word’s language from five options 85.6% of the time.
